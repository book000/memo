# Windows 11 の初期設定（OOBE）でローカルアカウントを作成する

Windows 11 の初期設定（OOBE: Out-of-Box Experience）で、Microsoft アカウントを使わずにローカルアカウントを作る方法をまとめる。

## 検証した環境

- Windows 11 26H2、Home と Pro、日本語版（Proxmox VE 上の仮想マシン）
  - インストールメディアは `10.0.26300.9457`（`Windows11_Client_x64_ja-jp_26300_9457.iso`）
  - ネットワークがあると OOBE 中に更新が入り、`10.0.26300.9711`（KB5127648）になる
- 25H2 のメディアは未確認
- Insider Preview のビルドは未確認

OOBE の挙動はビルドごとに変わる。ここに書いた内容は上記のビルドでの結果で、他のビルドでは未確認。

## 方法の選び方

| 状況 | 使う方法 |
|---|---|
| Pro で、ネットワークに接続済み | 下の `Pro の「ドメインに参加する」経路` の節 |
| Home で、ネットワークに接続済み | `start ms-cxh:localonly` |
| Home で、ネットワークに接続していない（ケーブルを抜いている、Wi-Fi に未接続など） | `start ms-cxh:localonly` または `BypassNRO.cmd` |
| Pro で、ネットワークに接続していない | `BypassNRO.cmd`（Pro での `start ms-cxh:localonly` は未確認） |

ネットワーク画面で `次へ` が押せる状態（接続済み）だと、`インターネットに接続していません` のリンクは表示されない。Home では、ここから Microsoft アカウントのサインイン画面に進んでも、ローカルアカウントに切り替える導線はない。Pro は下の「ドメインに参加する」経路がある。

## Pro の「ドメインに参加する」経路

Pro だけに出る画面を使う。コマンドは不要で、ネットワークに接続したまま進められる。

1. ネットワークに接続した状態で OOBE を進める。更新の確認（数分かかる）のあと、`デバイス名を入力` が出る（`スキップ` できる）
2. `このデバイスをどのように設定しますか?` で、`職場または学校用に設定する` を選んで `次へ`
3. Microsoft のサインイン画面で、メールアドレス欄の下の `サインイン オプション` をクリック
4. `顔、指紋、PIN、またはセキュリティ キー` と `代わりにドメインに参加する` が表示されるので、`代わりにドメインに参加する` をクリック
5. `このデバイスを使うのはだれですか?` に進む。以降は「ローカルアカウントの入力画面」と同じ

Home には `このデバイスをどのように設定しますか?` の画面がない。Home でこの経路は使えない。

## `start ms-cxh:localonly`

OOBE の画面から、ローカルアカウントの作成ウィンドウを直接開く。

1. OOBE の画面（`ネットワークに接続しましょう` や `Microsoft エクスペリエンスのロックを解除する`）で ++shift+f10++ を押し、コマンド プロンプトを開く
2. 次のコマンドを実行する

    ```cmd
    start ms-cxh:localonly
    ```

3. `この PC のユーザーを作成します` というウィンドウが開く。ユーザー名、パスワード（2 回）、パスワードを忘れた場合の質問 3 問と答えを入力して `次へ(N)` を押す
4. `もう少しで完了です。` → `デバイスのプライバシー設定の選択` → デスクトップの順に進む

26300.9457 と 26300.9711 の Home で、26300.9457 ではネットワークなし、26300.9711 ではネットワークありで動いた。`BypassNRO.cmd` を先に実行する必要はない。`start ms-cxh://LOCALONLY` も同じ結果だった。

Pro で単独に試した結果は未確認。Insider Preview 26220.6772 では無効化されたという報告がある（二次情報で、実機では未確認）。使えないビルドでは、次の `BypassNRO.cmd` を試す。ただし、同じ報告では `BypassNRO.cmd` も使えなくなったとされている（二次情報、未確認）。

## `BypassNRO.cmd`

ネットワーク要件を飛ばして、`インターネットに接続していません` のリンクを出す。ネットワークに接続していないときだけ効く。

1. ネットワークから切り離す（LAN ケーブルを抜き、Wi-Fi にも接続しない）
2. OOBE で ++shift+f10++ を押し、コマンド プロンプトを開く
3. 次のコマンドを実行する。自動で再起動し、OOBE が国の選択から再開する

    ```cmd
    oobe\BypassNRO.cmd
    ```

4. 国の設定とキーボード レイアウトのあと、`ネットワークに接続しましょう` に `インターネットに接続していません` のリンクが表示される。これをクリックする
5. `このデバイスを使うのはだれですか?` に進む。以降は「ローカルアカウントの入力画面」と同じ

確認できたこと:

- `C:\Windows\System32\oobe\BypassNRO.cmd` は 26300.9457 と 26300.9711 の Home、26300.9457 の Pro に存在する（124 バイト、更新日 2024/04/01）。Microsoft がこのファイルを削除したという情報があるが、このビルドでは残っていた
- ファイルの中身は次の 3 行。ファイルがないビルドでは、`reg add` と `shutdown` の 2 行を手で実行すれば同じになるはず（この手動実行は未検証）

    ```cmd
    @echo off
    reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE /v BypassNRO /t REG_DWORD /d 1 /f
    shutdown /r /t 0
    ```

- `インターネットに接続していません` を押したあと、`今すぐ接続して、デバイスをすぐに使い始めましょう` と `制限された設定で続行` の画面は出なかった。名前の入力画面に直接進む
- ネットワークに接続済みだと効かない。再起動してもネットワーク画面が出ず、`Microsoft エクスペリエンスのロックを解除する` に戻る

## ローカルアカウントの入力画面

どの方法でも、入力する内容は同じ。

1. `このデバイスを使うのはだれですか?`: ユーザー名を入力する。`C:\Users\<ユーザー名>` のフォルダ名になる（`デバイス名を入力` の画面で別名を指定した場合を除く）ので、アルファベットで入力するのが無難
2. `確実に覚えやすいパスワードを作成します`: パスワードを入力し、次の画面で再入力する
3. `ここでセキュリティの質問を追加します`: 6 種類から 3 問を選び、答えを入力する。3 問とも必須
4. `デバイスのプライバシー設定の選択`: 5 つのトグル（位置情報、デバイスの検索、診断データ、手書き入力とタイプ入力、パーソナライズされたオファー）が表示される。すべてオンが初期値。オフにする場合は、1 つ切り替えるたびに説明文の長さが変わって配置がずれるので、画面を見ながら操作する。最下部までスクロールすると `次へ` が `同意` に変わる
5. `準備しています。` のあと、デスクトップが表示される

## 確認できなかったこと

- 25H2 のメディアでの動作
- Pro での `start ms-cxh:localonly` の単独の動作
- `WinJS.Application.restart("ms-cxh://LOCALONLY")` を開発者ツールのコンソールで実行する方法。OOBE で ++ctrl+shift+j++、++f12++、++ctrl+shift+i++ を押してもコンソールは開かなかった（26300.9457、Home）
- Windows 11 の更新後に Microsoft アカウントからローカルアカウントへ切り替える手順
